\begin{quote}\small
\textbf{Early-window selection with cutoff \(K\).}\\
For each reached query \(q\), encode the current observation once.\\
Set \(N_q=4\) when \(q\le K\), and set \(N_q=1\) otherwise.\\
Denoise \(N_q\) independent proposals with the shared prefix.\\
If \(N_q>1\), score the proposals and choose the highest twin-min score.\\
Otherwise select the single proposal. Execute up to the action horizon.
