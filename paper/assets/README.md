# Recorded LIBERO-Object input frames

The frames are byte-preserving PNG exports from the existing EWS-5 rollout
`object_t0_fresh14`, recorded in the `front0` ledger of the fresh Object
evaluation. Each input is 256 × 256 pixels. The wrist image shares the first
query with the corresponding external view. The teaser displays the odd
queries and shows all reached queries on the schedule strip. The example
rollout illustrates the policy; the plot beside it uses the matched Graph
cohort as a separate aggregate.
